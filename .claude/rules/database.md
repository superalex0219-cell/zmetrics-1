# Database Rules

## Schema conventions

- Primary keys: `UUID`, Python-side `default=uuid.uuid4` (not server-side)
- All mutable tables inherit `TimestampMixin` (`created_at`, `updated_at` with `server_default=func.now()`)
- Soft-deleted tables (quarry, site_section) inherit `SoftDeleteMixin` (`deleted_at`)
- Enum columns: define Python `str, enum.Enum`; use `SAEnum(MyEnum, name="enum_name")` in column
- JSONB for: calibration matrices, pipeline_log, parameter_suggestions, size_distribution, metrics
- `AuditLog` is append-only — never add `updated_at` or soft delete to it

## Naming

- Table names: `snake_case`, singular (e.g., `blast_passport`, not `blast_passports`)
- Column names: `snake_case`
- Index names: `ix_{table}_{column}`
- FK constraint names: auto-generated by SQLAlchemy is fine
- Unique constraint names: `uq_{table}_{columns}` (e.g., `uq_quarry_user_active`)
- Enum type names: `{enum_name}` lowercase (e.g., `passport_status`, `job_status`)

## Alembic migrations

- Always `alembic revision --autogenerate` after model changes; never hand-write migrations from scratch
- Review generated migration before applying: check enum creation order, index inclusion
- Enums must be created before their tables in `upgrade()`; dropped after tables in `downgrade()`
- Migration `env.py` uses async pattern (`asyncio.run(run_async_migrations())`); do not revert to sync
- Never edit applied migrations; create a new one instead

## Indexes

Add explicit indexes for:
- All FKs that are queried (most are; add `index=True` on the `mapped_column`)
- `AuditLog.occurred_at` (for time-range queries)
- `AnalysisJob.celery_task_id` (status polling)
- `UserProfile.keycloak_sub` (login lookup)

Do NOT index every column speculatively; add when a query needs it.

## Soft delete

Soft-deleted records (`deleted_at IS NOT NULL`) must be excluded from:
- All list endpoints
- All FK joins that produce lists
- Include them only in explicit "include_deleted=true" admin queries

## Data types and units

- Sizes always `Numeric(N, 3)` in **millimeters** (P10/P50/P80, hole_diameter_mm)
- Distances always `Numeric(8, 2)` in **meters** (burden_m, spacing_m, depth_m)
- Masses always `Numeric(10, 3)` in **kilograms**
- Volumes always `Numeric(12, 4)` in **cubic meters**
- Percentages always `Numeric(6, 3)` (0.000–100.000)
- Confidence scores always `Numeric(5, 4)` (0.0000–1.0000)
